| How to earn | Amount |

## 🎲 Gambling

> Risk your Phonk Points for a chance to double up.

### `!gamble [amount]`

Coin flip. Win = **2×** your bet. Lose = gone.

### `!slots [amount]`

3-reel slot machine. Symbols: 🎵 🔥 💀 ⚡ 🌙 👾

| Result | Payout |
|---|---|
| 🎵 🎵 🎵 — 3 matching | **5× Jackpot** |
| Any 2 matching | **2×** |
| No match | **0 — lose bet** |

> Both commands: 10 second cooldown per user.

## 🔥 Engagement

| Command | What it does |
|---|---|
| `!hype` | Adds 1 to the hype meter on stream. At **15 votes** the overlay flashes and chat gets a shoutout. Earns **+2 pts**. |
| `!vibe` | Posts a random phonk atmosphere line |
| `!fire` | Vote the current track as 🔥 fire — tally shown in chat |
| `!trash` | Vote the current track as 💀 trash — tally shown in chat |
| `!lurk` | Acknowledge your lurk + earn **+5 pts** |

> `!fire` / `!trash` — once per track per viewer. Votes reset when the song changes.  
> `!hype` — 60 second cooldown per user, resets after each round.

## 📝 Notes

| Term | Meaning |
|---|---|
| **Global cooldown** | One person triggers the cooldown for the whole chat |
| **Per user cooldown** | Each viewer has their own independent timer |

- Phonk Points are stored per-browser session — they persist across streams but reset if browser data is cleared
- The hype meter resets 3 seconds after reaching 15 votes
- The `!fire` / `!trash` vote resets automatically when the track changes
